# Examen final — banque de questions / Final exam question bank

> Lot 3A — brouillon à valider. 40 questions ; 20 tirées au hasard par
> tentative, avec au moins 6 questions du module 2 ; 80 % pour réussir.
> Chaque question existe en FR et en EN (traduction EN à la production).
> La bonne réponse est en gras.

## Module 0–1 (8)
1. Statut sur FutureTutor : employé / **prestataire indépendant** / bénévole.
2. Une occasion ne vous convient pas : **la refuser** / l'accepter puis annuler / l'ignorer.
3. Rémunération connue : après la séance / **avant d'accepter** / à la fin du mois.
4. Une disponibilité n'est plus valable : **la retirer** / attendre / refuser chaque invitation.
5. Bio : peut promettre une note / **ne promet aucun résultat**.
6. Échanger avec une famille : **messagerie FutureTutor** / téléphone personnel / réseau social.
7. Parent observateur : le désactiver / **continuer normalement**.
8. Versements : en espèces / **par Stripe** / par virement direct de la famille.

## Module 2 (12)
9. Un élève de 13 ans écrit sur un réseau social : **ramener sur la messagerie FutureTutor** / répondre sur le réseau.
10. Danger immédiat : **secours puis FutureTutor** / attendre la prochaine séance.
11. Signaler à FutureTutor remplace l'obligation légale : oui / **non**.
12. Cadeau spontané de 20 $ : **acceptable** / interdit.
13. Cadeau de 60 $ : accepté / **refusé poliment**.
14. Solliciter un cadeau : permis si petit / **jamais**.
15. Demander à un élève de garder un échange secret : **jamais** / si c'est pédagogique.
16. Rencontrer un élève hors du cadre autorisé : **jamais** / si le parent est d'accord par texto.
17. Garder les coordonnées d'élèves dans un fichier personnel : oui / **non**.
18. Un élève semble en détresse : enquêter soi-même / **écouter sans enquêter et signaler**.
19. Partager son compte FutureTutor avec un collègue : **jamais** / pour un remplacement.
20. S'abonner aux réseaux sociaux d'un élève mineur : **inapproprié** / approprié.

## Module 3 (8)
21. Première étape d'une séance : **diagnostic** / exercices du chapitre.
22. Objectifs par séance : **un objectif clair** / le plus possible.
23. Pendant la pratique, qui travaille : **l'élève** / le tuteur.
24. Meilleure vérification : **« réexplique avec tes mots »** / « tu as compris ? ».
25. « Je suis nul » : **explorer un exercice concret ensemble** / « c'est facile ».
26. Feedback utile : **précis et orienté vers la prochaine étape** / « bien » ou « pas bien ».
27. Élève avec besoins particuliers : poser un diagnostic / **adapter rythme et supports, dialoguer avec le parent**.
28. Garantir 90 % : permis / **jamais**.

## Module 4 (5)
29. Avant de partager l'écran : **fermer les fenêtres personnelles** / rien.
30. Enregistrer une séance pour l'élève : **non** / oui s'il le demande.
31. Connexion coupée : **prévenir par la messagerie et se reconnecter** / attendre la séance suivante.
32. Enregistrer la présence de l'élève à sa place : **jamais** / s'il a un empêchement.
33. Arrière-plan : **professionnel, rien de privé** / aucune importance.

## Module 5 (4)
34. Rédiger un travail noté : **interdit** / permis si l'élève est en retard.
35. Commenter un brouillon : **permis** / interdit.
36. Continuer en privé avec une famille présentée par FutureTutor pour éviter les frais : **non** / oui.
37. Parent agressif : **rester courtois et informer FutureTutor** / répondre sur le même ton.

## Module 6 (3)
38. 20 minutes de retard sans message : **absence** / séance normale.
39. Malade le matin d'une séance : **prévenir FutureTutor au plus tôt** / ne rien dire.
40. Déclaration des revenus : **le tuteur** / FutureTutor.
