# FutureTutor public image brief

The public experience uses the approved FutureTutor editorial image library below. Original PNG masters remain intact in `public/images`; Next.js supplies optimized responsive delivery at runtime.

Approved narrative roles and source files:

1. Parent/student hero: `parents-students-hero.png`.
2. Tutor hero: `tutor-hero.png`.
3. Understanding: `learning-breakthrough.png`.
4. Online tutoring: `online-tutoring.png`.
5. About/mission: `about-mission.png`.
6. Authentication: `auth-editorial-1.png` through `auth-editorial-5.png`, selected per page load and shown only in the desktop editorial panel.

Direction: bright natural light, credible Canadian diversity, active transmission, uncluttered environments, restrained expressions. Avoid classrooms staged as stock photography, graduation symbols, books-as-decoration, AI motifs, magical glow, exaggerated celebration, and fictional customer attribution.

The localized alt-text decisions live in `messages/en.json` and `messages/fr.json`. Authentication portraits share a neutral description because any one of the five approved portraits may be selected at runtime.
